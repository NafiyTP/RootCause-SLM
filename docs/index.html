Research · Interpretability 2026
PyTorch TransformerLens Activation Patching State-Space Models

Induction circuits: Transformers vs. state-space models

A mechanistic-interpretability study asking whether Transformers and Mamba-style state-space models solve in-context induction the same way. It connects a background in state-space theory and filtering (Kalman, ARMA) directly to circuit-level analysis of modern sequence models.

Induction accuracy, best checkpoint

Transformer
85.4%
Mamba (SSM)
86.9%
  • Built the full stack from scratch: an induction-task generator, a TransformerLens baseline, and a minimal Mamba block in pure PyTorch, wired up for activation patching and pole/eigenvalue analysis.
  • Transformer reaches 85.4% induction accuracy through a circuit localized to two attention heads in layer 1. Patching those heads alone recovers 68–80% of full performance.
  • Mamba reaches 86.9% once a subtle bug was found and fixed: AdamW's weight decay was quietly preventing the induction circuit from forming at all.
  • Unlike the Transformer, Mamba's circuit is distributed across all of layer 1. No single channel is individually necessary or sufficient, and the "slow pole ⇒ important channel" hypothesis doesn't hold up (near-zero correlation).
Applied ML · LLMOps May–Jul 2026
PyTorch HuggingFace LoRA Qwen2.5 Llama-3.3-70B

RootCause-SLM: AIOps log anomaly detection

An end-to-end AIOps pipeline that fine-tunes a small language model to flag and explain anomalies in HDFS system logs, using a much larger model as a teacher.

  • Distilled annotations from Llama-3.3-70B (via Groq) to fine-tune Qwen2.5-1.5B-Instruct with LoRA over 5 epochs, best validation loss 0.099.
  • Countered heavy class imbalance in the log data with a WeightedRandomSampler.
  • Built an evaluation harness around ROUGE-L and BERTScore for judging generated explanations.
Applied ML · Multi-Agent Systems Mar–Jun 2025
Python OpenAI API HuggingFace CUDA

Secretary-AI: multi-agent medical secretary automation

A multi-agent system that automates repetitive work inside a medical secretariat: scheduling appointments, triaging inbox messages, drafting prescriptions, all behind one consistent model interface.

  • Designed a common BaseAIModel interface so agents can call an external API (OpenAI) or run local inference (HuggingFace Transformers on CUDA) with no change to agent logic.
